# n8n Node Package Auditor MVP Implementation Plan

> **For Hermes:** Use test-driven-development skill while implementing this plan task-by-task.

**Goal:** Build a working CLI that scores n8n community-node package readiness and outputs text, JSON, and Markdown reports.

**Architecture:** A local-first TypeScript CLI reads a target package folder, evaluates deterministic checks, computes a weighted score, and formats results. No external API calls are required for the MVP.

**Tech Stack:** Node.js 20, TypeScript, Vitest, GitHub Actions.

---

## Tasks

1. Create project skeleton with `package.json`, `tsconfig.json`, `.gitignore`, `.env.example`, and source/test folders.
2. RED: write Vitest coverage for healthy package scoring, broken package findings, and report formatting.
3. GREEN: implement `auditPackage`, typed report models, and text/Markdown formatters.
4. Add CLI argument parsing for package path, output format, and minimum score gate.
5. Add healthy sample package fixture under `examples/healthy-package`.
6. Add README usage, development commands, scope, and roadmap.
7. Add CI workflow running `npm ci` and `npm run validate`.
8. Validate locally with lint, tests, build, and real CLI executions.
9. Initialize git, commit, publish GitHub repo, push, and verify CI.
